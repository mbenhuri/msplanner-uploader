Import

Upload a CSV or JSON file. Existing tasks are matched by the id column if present, otherwise by bucket + title, and updated in place rather than duplicated. percent_complete applies on create only, and a blank field never clears a value already set in Planner.

Export

Reads a plan back into the same CSV format the importer accepts. The id column holds real Planner task IDs, so an exported file re-imports safely even from a clean checkout.

Signed in with delegated permissions — this app can only reach plans whose Microsoft 365 group you are a member of.
